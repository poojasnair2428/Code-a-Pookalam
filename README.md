# 🌺 Onam Pookalam - 2D Floral Carpet Generator

A Python-based procedural artwork generator that programmatically renders traditional Onam Pookalam (floral carpets) using `matplotlib` and `numpy`.

The project recreates realistic floral designs featuring complex geometric layers—including checkered outer borders, interlocking diamond meshes, starburst petals, and micro-scattered floral particle textures—all generated on a clean 2D canvas.

## ✨ Features

* **Procedural Geometry:** Dynamically constructs complex concentric layers, starburst arrays, and curved diamond meshes.
* **Realistic Petal Texture:** Simulates micro-scattered flower petals with natural color noise and density variations.
* **Rich Color Palette:** Features traditional floral hues including marigold yellow, vibrant orange, deep maroon, leaf green, and violet.
* **Vector & Texture Blend:** Combines precise geometric polygons with dense scatter plots for seamless coverage without gaps.

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Core Libraries:** `matplotlib`, `numpy`
* **Environment:** Compatible with Google Colab, Jupyter Notebooks, and local Python scripts.
